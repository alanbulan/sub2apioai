# ticket292 updater

This updater builds the latest official `Wei-Shaw/sub2api` release with the
functional changes from `feat/openai-codex-turn-state-ticket`.

It resolves and records two immutable inputs for every deployment:

- the latest official release tag and peeled commit;
- the current feature branch commit and the SHA256 of its generated diff.

The feature diff is generated by GitHub from the exact feature commit. Changes
under `.github/` and this directory are excluded because they manage the fork
and deployment process rather than the application.

If the patch does not apply, the build fails, or the health check fails, the
installed service is kept or rolled back. The installed updater refreshes
itself from this directory using the resolved feature commit before each run.

Run a source compatibility check without building or restarting the service:

```bash
/usr/local/sbin/sub2api-auto-upgrade.sh --check-only
```
